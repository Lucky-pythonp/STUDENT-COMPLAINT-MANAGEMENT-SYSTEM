# Student Complaint Management System

The Student Complaint Management System is a web-based application developed using Python and Streamlit to simplify the process of submitting and managing student complaints. It allows students to submit complaints related to academics, faculty, college facilities, infrastructure, and other campus-related issues.

Students can submit complaints, view their complaint history, and track complaint status. The administrator can manage complaints, update their status, and monitor issues through an admin dashboard.

The main objective of this project is to make the complaint management process simple, transparent, organized, and efficient while reducing paperwork and improving communication between students and college administration.

**Key Features:**
- Student registration and login
- Submit complaints with category and description
- View complaint history
- Track complaint status
- Admin dashboard for complaint management
- Update complaint status to Pending, In Progress, or Resolved
- Store and manage complaint records

**Technology Stack:**
- Programming Language: Python
- Frontend and UI: Streamlit
- Backend Logic: Python
- Database: SQLite
- Development Tool: Visual Studio Code

**Objective:** To develop a user-friendly digital platform that enables students to report campus-related problems and helps administrators manage and resolve complaints efficiently.
